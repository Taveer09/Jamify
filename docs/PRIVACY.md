# Конфиденциальность Jamify

Эта страница описывает поведение текущей локальной версии приложения. Она не обещает безопасность от вредоносных расширений браузера, XSS или доступа к устройству.

## Данные и хранение

- Jamify использует Spotify OAuth Authorization Code с PKCE. В `sessionStorage` находятся refresh token и временные данные OAuth/PKCE; access token хранится только в памяти приложения. Client ID является публичной настройкой приложения, Client Secret не используется.
- Локальные черновики и журнал решений, демо-плейлисты и журнал операций записываются в IndexedDB текущего браузерного профиля. Записи черновиков привязаны к Spotify account ID и playlist ID.
- Черновики старше 30 дней удаляются при следующей загрузке. Незавершённая операция не удаляется по TTL: журнал сохраняется, пока результат не будет сверён. Очистка данных аккаунта блокируется, пока у него есть незавершённая операция.
- Выйти из аккаунта или очистить данные можно в приложении. Очистка данных браузера также может удалить локальные черновики и демо-плейлисты; не удаляйте данные, если ещё требуется сверить незавершённую операцию.

## Запросы и аудио

- В live-режиме браузер напрямую обращается к Spotify Accounts и Spotify Web API. Приложение запрашивает scopes: `playlist-read-private`, `playlist-modify-private`, `playlist-modify-public`, `streaming`, `user-read-playback-state`, `user-modify-playback-state`, `user-read-private`, `user-read-email`. Разрешения на изменение нужны только для действий, явно запущенных пользователем.
- Spotify отвечает за обработку данных в OAuth и API. Jamify не загружает и не сохраняет live-аудио Spotify; потоковое воспроизведение остаётся на стороне Spotify.
- Демо использует вымышленные плейлисты и локальные короткие аудиофайлы проекта. Эти демо-аудио опубликованы под CC0-1.0.
- Приложение не отправляет данные в собственный сервер или серверную базу данных. Оно не использует AI API.

## Удаление локальных данных

В текущем демо-интерфейсе доступна очистка демо-плейлистов и решений. Очистка хранилища аккаунта блокируется, если его операция ещё не сверена, чтобы сохранить журнал для reconciliation. После разрешения незавершённых операций локальные данные также можно удалить через настройки браузера.
