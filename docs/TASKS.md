Общий префикс каждого задания после согласования:

Проверки из шага выполни и укажи реальные результаты, незапущенное пометь not-run. В конце обнови статус шага и передай следующей сессии изменённые файлы, открытые риски и точную команду проверки. Пользователь сам входит в Spotify и задаёт Client ID; пароль/Client Secret не нужны. Документируй результат без токенов, пересчитай оставшиеся часы. Если live недоступен — зафиксируй блокер, выполни независимые mock-проверки, не объявляй S0 полностью закрытым.

### D — S4, Sol high

Финализируй baseline/решения/undo/журнал одной локальной транзакцией; проверь «25 → apply → reload → карточка 26 → второй apply» и crash после server verify. ## Текущая desktop-поправка

Пользователь явно расширил чтение до медиатеки/Любимых и потребовал все треки за проход. Root интегрирует additive live-read путь отдельно от mutation coordinator; UI исполнитель меняет общую музыкальную сцену/стили, независимые ревьюеры проверяют lifecycle и итоговый рендер.
