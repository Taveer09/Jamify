# Jamify demo assets

Три 8-секундных WAV-фрагмента синтезированы для Jamify: синусоидальные тоны с собственными огибающими. Это не записи Spotify и не музыка сторонних исполнителей. SVG-обложки созданы в проекте. Названия треков и исполнителей вымышлены. Assets разрешены для использования и распространения вместе с Jamify (CC0-1.0).
